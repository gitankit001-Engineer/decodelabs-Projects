2️⃣ Iris Flower Prediction System 🌸
📖 Overview

This Machine Learning project predicts the species of Iris flowers using flower measurements such as:

Sepal Length
Sepal Width
Petal Length
Petal Width

The model classifies flowers into:

Iris Setosa
Iris Versicolor
Iris Virginica
🚀 Features
ML-based flower prediction
Trained on Iris dataset
Feature importance analysis
Accuracy evaluation
Real-time prediction
🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-learn
Matplotlib

3️⃣ AI Job Recommendation System 💼
📖 Overview

The AI Job Recommendation System recommends suitable technology careers based on user skills using AI similarity matching techniques.

This project works like a digital career matchmaker that compares user skills with job requirements and recommends the most suitable roles.

🚀 Features
AI-powered job recommendations
Skill similarity matching
TF-IDF vectorization
Cosine similarity scoring
Smart ranking system
Multiple job suggestions
🛠️ Technologies Used
Python
Pandas
Scikit-learn
TF-IDF Vectorizer
Cosine Similarity
